## Audience

- Customer Azure IT Admin team
- Customer Network team
- Customer SecOps team
- Customer VMware operators (if separate from Azure)

## Format

| Session | Duration | Format | Recording |
|---|---|---|---|
| Overview + landing zone tour | 1 h | Walkthrough + Q&amp;A | ✅ |
| AVS portal | 1 h | Demo | ✅ |
| vCenter on AVS | 1.5 h | Demo + hands-on | ✅ |
| NSX-T Manager (DFW, segments, T0/T1, IDS/IPS) | 2 h | Demo + hands-on | ✅ |
| HCX dashboard + future migrations | 1 h | Demo | ✅ |
| Monitoring stack (Azure Monitor, Defender, Sentinel) | 1.5 h | Demo + hands-on | ✅ |
| Backup + restore drill | 1 h | Hands-on | ✅ |
| DR fail-over (tabletop or partial) | 2 h | Tabletop + hands-on | ✅ |
| Runbook library tour | 1 h | Walkthrough | ✅ |
| Joint support case process (Microsoft + VMware) | 0.5 h | Walkthrough | ✅ |
| Q&amp;A wrap-up | 1 h | Open Q&amp;A | ✅ |

## Pre-requisites

- Customer access to AVS portal confirmed
- vCenter / NSX-T cloudadmin credentials handed over (via secure channel)
- Customer attendees nominated per session
- Recordings repository identified (SharePoint / Stream)

## Acceptance

- [ ] All sessions completed
- [ ] Recordings filed
- [ ] Q&amp;A log filed
- [ ] Customer sign-off email received
