## What the Auditor Checks

The auditor verifies that you produced a **skilling plan** covering: (1) new skills for technical roles (IT Admin / Governance / Operations / Security) and (2) knowledge-transfer resources including Microsoft Learn paths and relevant certifications.

> *(Note: the V1.9.1 checklist also lists a "TAGA report" requirement for AI specializations — N/A for AVS.)*

**Typical questions:**
- Show the skilling plan delivered to two customers.
- Which Microsoft Learn paths and certifications are mapped to the technical roles in scope?
- How is the plan tracked to completion?

| # | Evidence Item | Accepted Formats | Status |

> Reference: [How to Build a Skilling Readiness Plan](https://learn.microsoft.com/training/).

## Common Gaps

- **Generic "training catalogue" with no role mapping**: Must show role → skill → Learn path mapping.
- **No tracking**: Plan must show completion tracking or a follow-up cadence.
- **No KT artefacts**: If recordings / runbooks aren't available, the plan looks aspirational.
