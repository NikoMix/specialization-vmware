## What the Auditor Checks

The auditor verifies that you have a **plan for tracking adoption projects** — analytics, application modernisation, AI initiatives — and that the plan is backed by quantitative evidence (cost, DevOps capability).

**Typical questions:**
- Show the adoption plan you produced for two customers, including milestones and tracking cadence.
- Where is the Cost Management report and Pricing Calculator output for each project?
- Where is the DevOps Capability Assessment report for each project?

<Aside type="tip">
  A single project plan that bakes in cost tracking (Cost Management export) and a DevOps maturity
  view (DevOps Capability Assessment) covers both required assessments and the adoption plan in one
  artefact.
</Aside>

## Evidence Guidance

### Cost Management + Pricing Calculator

- Export Cost Management report (subscription or resource group scope) for the customer's AVS + adjacent Azure resources
- Include the **Pricing Calculator** output used during planning (e.g. AV36 reservation sizing, ANF volume costs, ExpressRoute circuit pricing)
- Annotate to show how cost projections fed into the adoption plan

### DevOps Capability Assessment

- Run the [DevOps Capability Assessment](https://learn.microsoft.com/azure/devops/) for the customer's delivery team
- Export the maturity report
- Identify the gaps that the adoption plan will address (e.g. release frequency, security shift-left)

### Adoption plan

Required elements:
- Workload waves and sequencing
- Milestones with target dates
- RACI / ownership
- Tracking cadence (weekly steerco / monthly exec)
- KPIs tied to the FinOps Review and CASE outputs from A.1.1

## Common Gaps

- **Pricing Calculator output missing**: Cost Management export alone is not enough — the planning-time Pricing Calculator output must also be present.
- **DevOps Capability Assessment treated as optional**: It is **required** per V1.9.1. Without it, A.1.2 fails.
- **Adoption plan with no tracking evidence**: A static plan is not enough — show the cadence (status report cadence, board screenshots, dashboard).
