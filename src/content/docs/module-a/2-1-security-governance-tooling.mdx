## Audit Gate

| Control name | What auditors check | Minimum evidence | Pass threshold |
|---|---|---|---|
| A.2.1 Security & Governance Tooling | Capability to deploy and operate governance and security tooling that establishes a customer security baseline and tracks remediation. Auditors expect both deployed tooling and an assessment-driven review. | For each of 2 customers: Microsoft Defender for Cloud or equivalent baseline evidence, Cloud Adoption Security Review output, governance configuration evidence (Azure Policy, RBAC, naming/tagging), and a remediation tracker. | 2 unique customers; evidence created within the last 12 months; a passed Module A result can be reused for 2 years. |

## Audit-ready evidence pack

1. Secure-score or equivalent baseline screenshot/export.
2. Cloud Adoption Security Review report with dated completion.
3. Policy, RBAC, and governance implementation evidence.
4. Remediation log showing owner, due date, and status.

## Common fail conditions

- Review completed but not linked to an actual deployed baseline.
- Third-party tooling used without explaining Azure control coverage.
- No remediation tracker showing that findings were actioned.
