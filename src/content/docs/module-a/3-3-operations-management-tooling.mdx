<Aside type="note">
  This control has two halves: operational tooling in production and an automated security or
  compliance pipeline that generates a sanitised artefact. Both must be visible in the evidence pack.
</Aside>

## Audit Gate

| Control name | What auditors check | Minimum evidence | Pass threshold |
|---|---|---|---|
| A.3.3 Operations Management Tooling | Operational monitoring, automation, backup, or recovery tooling deployed for the customer, plus an automated pipeline that runs security or compliance checks and produces an auditable artefact. | For each of 2 customers: evidence of Azure Monitor, Azure Automation, Azure Backup, or equivalent tooling; pipeline definition from GitHub Actions or Azure DevOps; one sanitised artefact such as a scan report, workbook export, SBOM, or policy-compliance snapshot. | 2 unique customers; evidence created within the last 12 months; a passed Module A result can be reused for 2 years. |

## Audit-ready evidence pack

1. Production operations-tool deployment screenshot or export.
2. Pipeline YAML and proof of execution.
3. Sanitised artefact tied to a specific pipeline run.
4. Optional supporting assessment such as Azure Advisor reliability output.

## Common fail conditions

- Operational tooling deployed with no automated compliance pipeline.
- Pipeline shown without a generated artefact.
- Artefact contains customer-sensitive data or lacks timestamps.
